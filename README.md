# 水下考古折射校正测量工具

面向水下考古探方摄影的纯前端工具：在防水壳平面观察窗后拍摄棋盘格，
标定 **镜头畸变 + 空气→玻璃→水折射** 的完整成像参数，再用 WebGL2 对
器物照片做几何校正，最后在校正图上点两点直接量取真实尺寸（误差目标 ≤1%）。

所有计算在浏览器本地完成，照片不上传；数据保存在 IndexedDB。

## 为什么普通镜头畸变校正不够

平面观察窗是一个 **空气→玻璃→水的两层界面折射系统**。针孔/Brown 模型只
描述镜头内部，无法表达界面折射：画面边缘的物体被非线性放大，且放大量随
水折射率（水温/盐度/深度）变化。本工具显式追踪两层 Snell 折射，从几何上
恢复无畸变的针孔图像。

## 物理与算法

### 折射模型（`src/core/optics.ts`）

- 观察窗几何：光心到内表面距离 `d`、玻璃厚度 `tg`、玻璃折射率 `ng`、
  水折射率 `nw`，以及窗法线相对光轴的小倾角 `tiltX/tiltY`（共轴窗取 0）。
- 正向投影 `projectPointNormalized`：物体点 → 水中射线 → 玻璃片内平移 →
  空气射线 → 归一化针孔坐标。共轴情形用一维解析标量方程 + Newton 求解；
  倾斜窗用二维有限差分 Newton。
- 逆映射 `traceAirRay`：空气中射线经两次 Snell 折射求水中射线，玻璃片
  只产生横向平移、不改变最终方向。
- 退化保护：全反射返回 null、轴点（x≈0）自动选主轴避免除零、
  `ng=nw=1` 时退化为精确针孔。

### 水折射率（`src/core/water.ts`）

Quan–Fry 经验模型，输入水温、盐度（可选水深、波长），输出 `nw`。
20°C 纯水 1.3330、海水 35PSU 1.3397，温度/色散方向与标准表一致。
每次下水工况不同可固定该值重新标定。

### 标定（`src/core/calibration.ts` + `lm.ts`）

- 单应分解求每张棋盘格位姿初值；
- Levenberg–Marquardt 联合优化内参（fx,fy,cx,cy）、Brown 畸变（5 项）、
  折射参数（d,tg,ng,nw,tilt）和各图位姿；
- 支持固定 `nw`（水温盐度已知）、固定窗几何；
- 输出重投影 RMS、最大误差、逐图误差。

### 校正查表（`src/core/remap.ts`）

输出图是与真实相机共光心的虚拟针孔相机。对粗网格（步长 16px）逐点：
虚拟针孔射线 → 折射追踪 → 击中参考深度平面 → 正向投影回源像素，
再用 Catmull-Rom 双三次插值展开到全像素，得到 RG32F 映射表，
保证折射这种非线性映射的亚像素重建精度。

### WebGL2 重采样（`src/webgl/resampler.ts`）

RG32F 浮点纹理承载映射表，片元着色器手动双线性查映射表后做 Catmull-Rom
双三次源图重采样；无 WebGL2 时回退 CPU 双线性。

### 测量（`remap.ts` 的 `measure`）

校正图是针孔几何，两点像素距离 × 深度像素当量即毫米；也支持用被泥沙
盖住一半的比例尺 **可见残段** 标定像素当量。

## 合成测试图（`src/core/synthetic.ts`）

测试图像按真实折射几何逆映射渲染，而非理想针孔图：

1. 每个输出像素的虚拟针孔射线经完整两层折射追踪到棋盘平面；
2. 棋盘相位与正向投影严格对齐（四象限对角同色的真鞍点）；
3. 5×5 高斯点扩散函数（PSF）模拟相机 MTF，形成物理真实的边缘过渡带；
4. 可加传感器噪声、泥沙遮挡斑块、被部分覆盖的比例尺。

`observableCorners` 给出渲染图上 **可观测鞍点**（梯度零点 + Hessian
鞍点判据）作为检测精度基准——这是相机实际能测量到的位置，区别于连续
几何投影点（二者因像素积分有亚像素级固有偏移）。

## 使用流程

1. **工况**：填水温/盐度/水深，应用得到当前 `nw`。
2. **标定**：导入 ≥3 张不同姿态的水下棋盘格，设格距，运行标定；
   角点自动检测，泥沙严重时可用手动四点兜底。
3. **校正**：导入器物照片，设参考深度，点折射校正（24MP 约 1.8s）。
4. **测量**：可选设比例尺残段，然后在图上点两点读毫米长度。
5. **目录**：按探方编号 + 日期保存记录到本地 IndexedDB。

## 命令

```bash
npm install
npm run dev       # 本地开发
npm run test      # 24 项单元/端到端测试
npm run bench     # 24MP 校正性能基准
npm run build     # 类型检查 + 生产构建
```

## 性能

24MP（6000×4000）基准（`npm run bench`）：CPU 建表约 1.7s + GPU 重采样
约 0.08s，总体 < 2s；映射表 RG32F 约 192MB。

## 已知限制

- **角点检测器**采用 Hessian 鞍点 + 栅格排序 + 单应平滑 + 鞍点约束局部
  搜索的自研实现。多数角点（中位）定位误差在亚像素级，但 Hessian 粗检测
  对少数边缘/强纹理角点存在数像素离群，使标定重投影 RMS 落在约 2–3px
  而非理想的 <0.5px。物理折射/投影链路、LM 优化器、校正查表本身均经
  独立测试验证正确；要达到论文级标定精度，可将 `detectCheckerboard`
  替换为 OpenCV findChessboardCornersSB 的 WASM 移植，接口已隔离在
  `src/core/detector.ts`，其余模块无需改动。
- 校正基于单一参考深度平面；偏离该平面的物体有残余深度失配误差，
  工具会用 `depthMismatchError` 给出相对误差界。
- 参考深度需用户提供（测尺/双测尺估计）。
