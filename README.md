# 水下探方摄影测量校正工具

针对平面玻璃窗防水壳的水下摄影测量: 在水中拍摄棋盘格完成折射标定, 导入探方照片按标定参数校正, 校正后照片上点两点即可量长度。纯网页工具, 离线可用, 数据不出本机。

## 快速开始

```bash
npm install
npm run dev        # 开发运行, 浏览器打开提示的地址
npm run build      # 产出 dist/(静态文件, 任意静态服务器可托管)
npm test           # 精度自检(18 项, 含 <0.5px 与 <1% 指标)
```

需要支持 WebGL2 的浏览器(Chrome / Edge)。目录归档功能(按探方/日期直接写盘)需要 Chrome / Edge; 其他浏览器退化为下载文件。

## 工作流程(每次下水)

1. **下水标定**: 输入壳体参数(玻璃折射率/厚度)、当次水温盐度(自动算出水折射率, 有折射仪可直接填)。水中拍摄 6–12 张棋盘格(不同位置/距离 0.5–1.5m/倾角, 覆盖画面四角), 检测角点后运行标定。要求重投影 **RMS < 0.5 px**, 界面会给出达标判定。
2. **照片校正**: 导入探方照片批量校正。校正为 WebGL2 逐像素重采样, 2400 万像素(6000×4000)单张远低于 2 秒, 界面显示每张耗时。
3. **量测**:
   - **比例尺残段**: 比例尺被泥沙盖住一半时, 在剩余可见段上点两个端点、输入该段真实长度, 工具由光线几何反推探方面深度, 之后点两点即得长度(假设近似垂直拍摄)。
   - **棋盘格定面**: 照片中含标定板时自动解算板平面, 量测为光线-平面求交的真实三维距离, 全画面精度一致, 不受拍摄倾角影响。
4. **档案目录**: 选定根目录后按 `<根目录>/<探方号>/<日期>/` 归档 `calibration.json`、`corrected/` 校正图、`measurements.json` 量测记录。
5. **合成自检**: 一键用真实折射几何合成测试图, 闭环验证标定 RMS、参数恢复、量测误差与 WebGL2/CPU 一致性, 可随时用来向所里演示精度指标。

## 物理模型

相机在防水壳内, 光线经 **空气→平面玻璃→水** 两层平行平面界面折射(矢量 Snell 定律)。平面平行玻璃只平移光线、不改变方向关系, 因此:

- **图像校正**只依赖方向映射: 校正图像素 → 水中方向 w → 反折射(切向分量放大 n水 倍) → 空气方向 → 镜头畸变 → 原图采样。超过水-空气全反射临界角(≈48.6°)的区域无对应光线, 填黑。
- **三维量测**还需要光线起点(玻璃外表面出射点), 由界面距离 dAir 与玻璃厚度决定, 标定时一并拟合。
- **标定**为光束法平差(LM): 拟合 fx, fy, cx, cy, k1, k2, dAir 及每视图棋盘格位姿; 正向投影用二维牛顿法解折射点。

### 为什么水折射率默认不拟合

平面标定板下焦距与水折射率存在近简并(畸变参数会吸收 Snell 非线性的差异), 自由拟合会得到 RMS 很低但物理参数错误的结果, 量测随之超差。因此 n水 由水温/盐度经验式给定(每次下水重新输入即完成"重新标定"):

```
n ≈ 1.33299 + 1.83e-4·盐度(PSU) − 1.0e-4·(水温°C − 20)   (589 nm)
```

确需拟合时可勾选"同时拟合 n"(带 σ=0.003 先验约束)。自检表明 n水 输入偏差 ±0.003 时标定与量测仍达标。

## 精度验证(合成数据, `npm test`)

- 折射几何: Snell 定律、正逆映射互逆、全反射临界角 —— 6 项
- 标定: 0.15 px 角点噪声下 RMS ≈ 0.15 px(< 0.5 px 指标); 焦距恢复 < 1%; 无噪声时 RMS < 0.01 px —— 7 项
- 量测: 定面模式与比例尺残段模式(含画面边缘、带噪声标定的端到端流程)误差均 < 1% —— 5 项

合成测试图由与标定/校正完全相同的两层界面光线追踪正向渲染, 构成闭环验证。

## 目录结构

```
src/refraction.ts    折射模型(正向追踪/反折射/投影/校正映射)
src/calibration.ts   LM 光束法平差 + 单应位姿初始化 + 单视图位姿解算
src/measure.ts       量测(定面/比例尺残段推面)
src/gl.ts            WebGL2 校正重采样
src/synth.ts         合成测试图(光线追踪)与合成位姿
src/chessboard.ts    OpenCV.js 角点检测(本地打包, 离线可用)
src/storage.ts       探方/日期目录归档(File System Access API)
src/main.ts          界面
tests/               精度自检( vitest )
```

## 注意事项

- 标定板格子边长务必用卡尺实测后输入, 它是一切长度量的基准。
- 比例尺残段模式假设近似垂直拍摄; 倾角大(>10°)时改用棋盘格定面。
- 量测假设目标在探方面上; 高出面的器物需按摄影测量多像交会处理(本工具范围之外)。
- 校正后图像边缘黑色区域为全反射临界角之外, 无对应物方光线, 属正常现象。
