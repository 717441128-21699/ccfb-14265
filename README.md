# 水下考古折射标定与测量工具

面向水下考古探方摄影的纯前端工具：解决相机透过平面玻璃窗（防水壳）在水下成像时的
**双界面 Snell 折射**问题，完成折射标定、正射校正与两点物理量测。TypeScript 实现，
重采样走 WebGL2，零运行时第三方依赖，数据本地存储不上传。

## 要解决的三个现场难题

1. **普通镜头畸变模型失效**：光线依次经 空气→玻璃→水 两个平行界面折射，折射量随入射角
   增大，画面边缘被非线性拉大，无法用径向畸变多项式描述。本工具按窗口法向、光心到玻璃
   距离 d0、玻璃厚度 t、玻璃/水折射率做**物理光线追踪**，不引入多项式近似。
2. **每次下水折射不同**：水温、盐度改变水的折射率（Quan–Fry 公式）。每次下水拍一组水下
   棋盘格，输入温盐后联合优化，输出独立的折射标定与重投影误差。
3. **比例尺被泥沙半遮挡**：只需剩余可见段两端点 + 可见段真实长度即可核对尺度；单根比例尺
   定平面的法向锥面歧义用探方朝向先验消歧并显式提示。

## 物理与数学模型

坐标系：相机系 x 右、y 下、z 朝前。窗口内表面 `n·X = d0`，外表面 `n·X = d0 + t`，
法向 n 可带装配倾斜。

- **后向光线**（`traceBackward`）：像素 → 空气光线 → 内表面 Snell → 玻璃 → 外表面 Snell →
  水中光线，全程解析矢量折射（Hecht 约定）。
- **前向投影**（`projectPoint`）：相机系 3D 点 → 像素，对像素坐标做牛顿迭代，使后向水中
  光线通过目标点；数值雅可比 + 二维最小二乘。
- **折射率**：水由 Quan & Fry (1995) 经验公式按 T/S/λ 计算；玻璃 n 由材料牌号给定（默认
  BK7=1.517）。
- **标定优化**：Levenberg–Marquardt，两阶段——先固定窗口参数求内参+各视角位姿，再放开
  窗口倾斜与玻璃厚度联合精修。d0（机械距离）与玻璃折射率作为已知量锁定；焦距先验用于
  消除单平面的焦距-深度歧义。
- **校正**：把照片重投影到探方物理平面生成正射影像，像素与毫米线性对应。
- **测量**：正射图上两点像素距离 × mm/px = 物理长度。

### 关于可辨识性（重要工程结论）

单张平面棋盘在中心视场下，焦距 fx 与各视角平移深度、d0 之间存在退化相关，低重投影误差
不保证这些参数各自准确。因此：

- d0 与玻璃折射率由**壳体装配图/玻璃牌号给定**，不作为自由标定参数；
- 焦距建议提供空气中标定或 EXIF 的**先验**（可锁定）；
- 主点默认钉在画面中心（平面端口装配误差小）；
- 标定视角需覆盖**不同拍摄距离与姿态**以打破尺度耦合。

## 目录结构

```
src/
  core/
    vec3.ts          向量/旋转(Rodrigues)/线性代数
    water.ts        Quan-Fry 温盐折射率
    model.ts        Snell 折射、后向光线、前向投影（核心物理）
    optimizer.ts    Levenberg-Marquardt（边界、数值雅可比）
    calibration.ts  多视角棋盘格联合标定
    rectify.ts      平面、正射帧、两点测量几何
    scalebar.ts     半遮挡比例尺、单比例尺平面求根（含歧义处理）
    synthetic.ts    按真实折射几何合成测试图/角点/比例尺/器物
    demoScene.ts    演示与测试共用的合成场景
    cpuRectify.ts   CPU 校正回退（GPU 结果的对照基准）
    png.ts          零依赖 PNG 编码器
  vision/checkerboard.ts  棋盘角点检测 + 网格拓扑
  webgl/rectifier.ts      WebGL2 着色器重采样
  storage/catalog.ts      IndexedDB 探方/日期目录
  ui/                     应用状态、测量工作流、演示数据
test/                     vitest 测试（合成数据，真实折射几何）
```

## 使用流程

1. 打开「折射标定」页，填探方、日期、水温盐度与窗口机械参数。
2. 导入 ≥3 张多距离多姿态的水下棋盘格照片（或点「载入合成演示图」离线试用）。
3. 开始标定，确认 RMS < 0.5px 后保存到目录。
4. 到「校正测量」页选标定、导入照片、生成正射校正图。
5. 在图上点两点即得毫米长度；比例尺半遮挡时先用可见段核对尺度。

## 已知限制

- 棋盘自动网格拓扑在大角度旋转/强遮挡下可能失败，此时返回空并提示手工标记（角点候选
  检测本身仍可靠，覆盖率有测试保证）。
- WebGL2 不可用时回退 CPU，大图像耗时显著增加。
- 单根比例尺无法唯一确定平面法向（几何本质），需朝向先验；有棋盘格时优先用棋盘定平面。
